# Khorezm Hometown Webpage

A simple responsive tourism webpage introducing the **Khorezm region of Uzbekistan**, its history, culture, architecture, and local activities.

This project was created as part of my HTML & CSS learning journey.

## 📸 About the Project

The webpage presents Khorezm as a tourist destination and includes:

* 🏛️ A hero section introducing Khorezm
* 🕌 Information about Khiva and Itchan Kala
* 🏰 Ancient fortresses of Khorezm
* 🍞 Traditional Khorezm food experience
* 👤 A personal guide section
* 🖼️ Images representing the region and its culture

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Background Images
* CSS Gradients
* Responsive viewport settings

## ✨ Features

### Hero Section

The landing section uses a background image with a dark gradient overlay.

```css
.header {
    background:
    linear-gradient(rgba(0,0,0,.7), rgba(0,0,0,0.5)),
    url("./images/xiva.jpg");
}
```

The section contains a main title and a short description of Khorezm.

### Activities Section

The website contains three activity cards:

1. **Khiva Historical City Tour**
2. **Three Ancient Fortresses Tour**
3. **Traditional Khorezm Food Master Class**

Each card contains an image, title, and description.

### Guide Section

The final section introduces the guide and contains a profile image, short description, and guide name.
